Гараж: приложение, которое есть и без колеса

Сейчас без подключения пользователь видит «Pick a vehicle», «0 found nearby» и три текстовые ссылки. Ниже — три варианта главного экрана и карточка транспорта. Все цифры — из записанных поездок, всегда с подписью «на когда». Поиск рядом идёт в фоне и не занимает экран.

Главный экран без подключения

Общее для всех трёх: вкладка «Гараж» вместо «Подключение», сканирование — маленький чип вверху, найденный рядом транспорт становится зелёным и подключается одним тапом. «Добавить» и «Демо» уходят вниз, мелко.

Принципы.
• Нет цифры без «на когда»: время записи у батареи, дата у поездки.
• Нет данных — нет плитки, а не «0».
• Поиск рядом не прячет гараж: найденный транспорт помечается «Рядом» и подключается тапом по «Подключиться».
• Технические вещи (гостевое подключение, ручной выбор типа устройства) — за «+ Добавить».

Чего пока нет в данных и потребует доработки: расход и дистанция в строке списка поездок (нужно читать итоги каждой поездки — сделаем с кешем), мини-маршрут в строке (есть превью из истории — переиспользуем).
