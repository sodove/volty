# Owned incoming notification publication

Publish only after the captured runtime's actual hint verification returns a fresh bounded
ring observation. Each publication uses a new opaque original notification ticket. The port
receives remaining monotonic credit for Android timeout; desired UI is not shown as an actual
published notification when the port refuses. Notification permission does not grant media.

One queued account-owned reader processes a latest-hint slot. Coalesce pending duplicates,
fence older results when a newer hint arrives, and withdraw earlier notification before
replacement. Account cancellation, explicit close, clock reset, pulse completion/failure and
credit expiry withdraw immediately. Count actual executing readers until completion even when
a response ignores cancellation; zero does not establish socket idleness. Borrow runtime and
account; never stop channel voice or close its HTTP children for notification cleanup.

Tests use actual runtime HTTP, expiry after publication, held response across logout and
replacement, refused notification and original ticket cancellation. Finite scheduling gates.
Action resolution/visible acceptance/decline, Android port and FCM binding are subsequent
tasks; no background delivery or hardware proof. Fresh Android suite before commit, manual
parent review and no new agents.
