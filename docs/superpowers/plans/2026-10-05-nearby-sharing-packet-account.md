# Sharing packets bound to original account/channel session

Extend the original account-owned sharing control with publication and audience reads. Capture
the actual CHANNEL destination from its typed original voice journal, not a UI supplied UUID.
Creation rechecks channel/session/account after bearer wait. Audience retains independent
sharing-reader ordinals; publication requires earned fresh own-consent generation/mode.

Revoke immediately tombstones that generation locally before root-owned negative HTTP; a held
positive response cannot restore it. New consent uses a new generation. Each publication owns
one temporary HTTP child with generation-specific bearer guards before and after refresh;
original root closes owned children without stopping borrowed authentication/audio. Audience
is exact captured channel/session and fences before/after all waits. Full disconnect/relogin,
lease expiry and explicit retirement deny positives; original revokes remain available.

Real existing voice-startup HTTP fixture tests first: earned consent publication/audience,
unknown generation zero packet HTTP, local hide preserves voice but blocks publication/start,
held publication discarded on hide, old account/session late audience discarded across same
user relogin while new runtime remains active. No offline revocation persistence or automatic
publisher/FGS/UI binding claims. Fresh exact full Android before commit.
