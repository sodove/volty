# Independent Nearby audio

The rider reported that Phone capture still used the Bluetooth microphone, and clarified that system-call routing is unnecessary. The former mandatory Telecom design is superseded for this audio increment. Incoming notifications remain separate from media routing.

Phone input now uses an owned AudioRecord with VOICE_RECOGNITION and explicit built-in microphone preference. Public ADM custom capture supplies paced PCM with internal SDK recording disabled. Every mute/reconnect/unpublish path also controls the final PCM gate; hardware effects are not falsely assumed installed on the disabled SDK recorder. Input is requested at 48 kHz. Partial hardware reads retain PCM across callbacks, but never across intent revisions or actual microphone changes. Explicit input admits only the owned stream's matching routedDevice; stale, muted, incomplete or retired frames are silenced.

Phone playback uses public RemoteAudioTrack sinks and independently owned MEDIA AudioTracks. Explicit Headset chooses A2DP/wired/USB/BLE output and admits voice only after the actual AudioTrack route matches. SDK playback is muted while this path runs. Noisy-device broadcasts release and block the disappearing output before it can fall back to a speaker. Auto/Headset microphone sessions retain SDK communication playback; transitions fence old AudioSwitch callbacks and update both playback owners. Native cleanup precedes SDK thread joins; sink teardown is fenced against late attachment and retained for cleanup retry.

The media focus request permits temporary music ducking instead of permanent focus loss. This supports mixing with music in Phone/A2DP mode; a player's own focus policy can still pause. Bluetooth latency, music behavior and physical microphone isolation remain device acceptance work. See [Android focus policy](https://developer.android.com/media/optimize/audio-focus) and the [public LiveKit sink implementation](https://github.com/livekit/client-sdk-android/blob/v2.25.3/livekit-android-sdk/src/main/java/io/livekit/android/room/track/RemoteAudioTrack.kt).
